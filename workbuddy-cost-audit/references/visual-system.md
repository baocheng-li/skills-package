# 全息前沿科技 B端 UI 视觉系统（工程落地版）

> 设计哲学：**等轴测微缩景观 + 材质强对比（实心 vs 玻璃）+ 全息光栅光影 + 动态科技凝固**。
>
> 本文不是灵感板，是可执行的规范：每一条都有对应的代码位置，改了哪里会影响哪里写得很清楚。
> 对应的实现是 `renderer/theme.py`（令牌）与 `renderer/icons.py`（3D 图标）。

---

## 1. 双主题

主题不是装饰偏好，是**场景自适应**：

| 主题 | 场景 | 底 | 主色 | 文字 |
|------|------|-----|------|------|
| Holo Dark | 监控大屏、长时间盯屏、环境光弱 | 深空蓝黑 `#060B19` | 量子蓝 `#0055FF` · 霓虹青 `#00FFFF` | `#E9F1FF` |
| Holo Light | SaaS 后台、白天、要打印 | 极浅冷灰蓝 `#F0F4F8` | 冰蓝 `#00D2FF` · 全息紫 `#9D4EDD` | `#2B3A55` |

切换方式：`<html data-skin="dark|light">`，页面右上角的圆形按钮，写 `localStorage`。

**关键约束：canvas 图表不认 CSS 变量。**
ECharts 已画好的像素不会因为变量变了就重算，所以切主题必须走
`refreshAllData(true)` 重绘（见 `p10_boot.js` 的 `bindSkin`）。
页面侧 `resolveColor()` 负责把 `var(--token)` 解析成具体色值，
色板仍然只有 `theme.py` 一份。

## 2. 材质规则

### 2.1 磨砂玻璃卡

```css
background: linear-gradient(158deg, var(--glass-1), var(--glass-2));
backdrop-filter: blur(10px) saturate(1.28);
border: 1px solid var(--glass-line);
box-shadow: var(--glass-shadow);
```

1px 全息描边不用 `border`，用 `mask-composite` 抠出**渐变边**：

```css
.card::before{
  padding:1px;
  background:linear-gradient(135deg,
    var(--glass-hi), transparent 32%, transparent 62%, var(--holo-edge));
  mask:linear-gradient(#000 0 0) content-box, linear-gradient(#000 0 0);
  mask-composite:exclude;
}
```

为什么不用 border：border 只能是单色，做不出「左上白光 → 右下霓虹青」的斜向过渡，
而那正是「高光边框」与「灰线框」的区别。

**blur 半径按元件分档**，不是一律 16px：

| 元件 | blur | 理由 |
|------|------|------|
| `.card` | 10px | 数量多（一屏 20–40 个），再大掉帧 |
| `.kpi` | 6px | 要浮在图表卡之上，更薄才有层次差 |
| `.sidebar` / `.topbar` | 14px | 大面积，糊得狠一点才有「玻璃板」感 |

### 2.2 全息网格底

```css
background-image:
  linear-gradient(var(--grid-line) 1px, transparent 1px),
  linear-gradient(90deg, var(--grid-line) 1px, transparent 1px);
background-size: 40px 40px, 40px 40px;
mask-image: radial-gradient(120% 90% at 50% 0%, #000 30%, transparent 82%);
```

40px 与 Carbon 的 8 倍数节奏同源；`mask` 让网格在视口边缘淡出，
避免四条硬边把「深空」切成一个方框。

### 2.3 扫描线

两条，都是 1px 级别，动画周期错开：

- **顶栏底部**：横向光带从左掠到右，7.5s 一轮，`opacity` 峰值 0.55；
- **整页**：180px 高的极淡光带自上而下，9s 一轮，`opacity` 0.5。

```css
@keyframes tbScan{0%{transform:translateX(-100%);opacity:0}
  12%{opacity:.55}62%,100%{transform:translateX(100%);opacity:0}}
```

`@media (prefers-reduced-motion:reduce)` 下全部压到 0.001ms——前庭敏感的人不该被闪。

### 2.4 状态色

沿用 Radix Colors 的 9/10/11/12 梯度（9 填充 / 10 悬停 / 11 深底正文 / 12 高对比）。
浅色主题取 Radix light 对应档位，**不要自己在白底上调红绿**——
对比度是被验证过的，手调十次有九次调到看不清。

规范里的「量子蓝 #0055FF」落在两处：
`--holo-blue`（发光、描边）与 `--pri`（半透明面用的 rgb 分量），
填充与文字仍用 Radix 9–12 档，保证深底上的可读性。

## 3. 3D 图标

### 3.1 三条硬约束（不满足即不合格）

1. **不孤立**：必须有双层底座（底层实体磨砂盘 + 上层全息网格环），
   主体悬浮其上，底座向外扩散能量波纹；
2. **有反差**：底层实心、上层高透、主体实心晶体——三种材质在同一张图里；
3. **全息感**：主体与底座之间有**垂直光柱**连接，四周有悬浮几何碎片。

垂直光柱不是装饰：没有它，主体看起来是「贴在底座上」而不是「悬浮」。

### 3.2 等轴测的数学落点

```
椭圆短半轴 = 长半轴 × (1/√3) ≈ 长半轴 × 0.5774
```

这就是「45° 等轴测」在 2D 里的投影比例，不是随手压扁的。
`icons.py` 里写作 `ISO = 1/1.7320508`（tan 30°）。

立方体按「顶面菱形 + 左暗面 + 右亮面」三段画，三面色分开传参，
这是「实心立体」那一半的材质反差来源。

### 3.3 尺寸降级，不是等比缩小

| 尺寸 | 用在哪 | 画什么 |
|------|--------|--------|
| 38px | 侧栏品牌位 | 全量：双层底座 + 光柱 + 环绕半圈 + 3 片碎片 + 3 颗粒子 |
| 20px | 导航项 | 降级版：主体占满 y=3…31，底座压到 y=33…41，只留底盘/发光环/主体三层次 |

18px 下如果按 48 网格等比缩小，主体只剩 8px 高，缩略图上就是一团色块。
降级版**牺牲一点透视比例换取可辨识度**——这是图标设计的常规做法。

### 3.4 语义映射

| 视图 | 图形 | 为什么 |
|------|------|--------|
| 监控总览 | 三根高低柱 | 消耗量随时间起伏 |
| 积分对账 | 两块叠放板 + 光环 | 账页 / 分录 |
| 任务监测 | 立起的表盘 + 指针 | 监测 / 时钟 |
| 对比分析 | 三级台阶 + 上升箭头 | 优化空间 |

### 3.5 取色

图标用 `var(--info-11)` / `var(--holo-cyan)` 等令牌取色，
换主题时**图标自动跟着变**，不需要出两套图。
渐变 `stop-color` 也支持 `var()`。

## 4. 组件映射

| 规范原话 | 落地位置 |
|----------|----------|
| UI 容器：磨砂玻璃卡 + 1px 高光/霓虹发光边框 | `.card` / `.kpi`（`01_head.html` + `theme.py`） |
| 数据图表：渐变自发光 + 节点呼吸泛光 | `p04_shell.js` 的 `paint()` + `TT` 令牌；`.glow-pulse` 只给 3 处用 |
| 全息扫描线掠过 | `.topbar::after`（7.5s）+ `.holo-scan`（9s） |
| 能量波纹扩散 | 3D 图标底座的 `iso_disc` 双层描边 |
| 数据流滚动 | 表格 hover 高亮 + 顶栏扫描 |
| 背景极微弱全息网格 / 光粒子 | `.holo-grid` + `.holo-aura` |

**发光要克制**：全页 `box-shadow: 0 0 Npx` 类发光不超过 6 处，
`glow-pulse` 呼吸动画不超过 3 处。加了十处发光，页面就不叫「全息」叫「故障」。

## 6. QA 清单

出图或改样式后，四项全过才算完成。每项都有对应的代码检查点：

- [ ] **不孤立** — 图标有双层底座 + 悬浮辅助几何体？
      检查：`icons.icon()` 里 `iso_disc` 调了两次以上，`detail=True` 时有碎片。
- [ ] **有反差** — 实心立体 vs 磨砂/高透玻璃的对比在？
      检查：图标 `iso_box` 三面不同色；卡片 `--glass-1` / `--glass-2` 有明度差。
- [ ] **全息感** — 有全息光栅 / 扫描线 / 发光边缘？
      检查：`.topbar::after` 的扫描动画在，`.card::before` 的斜向渐变边在。
- [ ] **光影净** — 阴影柔和、背景干净、没有廉价高光噪点？
      检查：`--glass-shadow` 用大半径低透明度；深色下没有 `rgba(0,0,0,1)` 硬阴影。

自动化部分由 TC-29 兜底：Radix 色阶与 Carbon 间距必须落成令牌，
正文规则里不许再出现旧色值，canvas 必须先过 `paint()` 解析。

## 7. 反面清单

| 不要 | 因为 |
|------|------|
| 每个卡片都加彩色发光 | 一屏 40 个光晕，读者找不到重点 |
| 用纯黑阴影 `rgba(0,0,0,.8)` | 浅色主题下会脏成一块；阴影要带环境色 |
| 图标一律等比缩小 | 20px 下细节糊成一团，要做尺寸降级 |
| 深浅主题各写一套 CSS | 必然漂移；令牌一处定义，两套只是换值 |
| 在白底上手调红绿 | Radix 的对比度梯度是被验证过的 |
| 扫描线 opacity > 0.6 | 变成「闪烁」，不是「全息」 |
